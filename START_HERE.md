# HackAlem kit: начните здесь

Это стартовый набор для трека финтех. 23.09 ровно в 13:00 вы копируете его в командный репозиторий.
Внутри три части:
1. **Процесс для Codex:** `AGENTS.md` (правила и карта проекта), 8 скиллов в `.agents/skills`, 3 агента-помощника в `.codex/agents`.
2. **Рабочая заготовка продукта:** финтех-агент на FastAPI со страницей. Маршрутизация моделей, инструменты, маскирование ПДн, учёт стоимости, демо-кэш. Уже работает без ключа (режим DEMO) и покрыт тестами.
3. **Шпаргалки:** этот файл, `docs/FINTECH_PLAYBOOK.md` (финтех Казахстана с источниками), шаблоны README и питча.

Всё, что сделано до хакатона, раскрыто в README, как требует п. 6.4. Не удаляйте этот раздел.

## 0. Каждому дома, до 23.09 (30 минут)

0. **Активируйте доступы** (PDF организаторов «Активация OpenAI и NVIDIA», ссылки и промокоды в боте):
   - **ChatGPT Pro и Codex:** откройте личную ссылку, войдите в ChatGPT. Подтверждайте, только если
     написано `Due today: $0`. Запишите дату следующего списания и отмените подписку до неё, если не хотите платить.
     В профиле должно быть Pro. Codex входите тем же аккаунтом. Codex работает по подписке и не тратит API-кредиты.
   - **API-кредиты команды:** ссылка API Credits, войти в OpenAI Platform, подтвердить промокод.
     Проверка: Billing, Promotions, Applied promotions. Затем platform.openai.com/api-keys, Create new secret key.
     Ключ хранится только в `.env` и в настройках Vercel. В GitHub ключи не публикуем (правило организаторов).
   - **NVIDIA Brev и Build:** по желанию. Заготовка работает на OpenAI, NVIDIA нужен, только если кейс попросит.
1. Установите **Python 3.11+** (python.org), **Git** (git-scm.com), **Node.js LTS** (nodejs.org, он нужен для деплоя).
   Python на Windows: в установщике отметьте «Add python.exe to PATH», затем «Customize installation»
   и «Install Python for all users». Так его увидит и Codex.
   Windows, одной командой в терминале: `winget install --id Git.Git -e --source winget` и `winget install OpenJS.NodeJS.LTS`.
   После установки закройте терминал и откройте новый, иначе команды `git` и `node` не найдутся.
   Один раз настройте git (почта та же, что в GitHub, иначе коммит не пройдёт):
   `git config --global user.name "Имя Фамилия"` и `git config --global user.email "почта@от.github"`
2. Установите **Codex**: приложение для Windows или macOS со страницы chatgpt.com/codex.
   Запасной вариант: в терминале `npm i -g @openai/codex`, потом команда `codex`.
3. Войдите в Codex через «Sign in with ChatGPT» тем аккаунтом, где активирован Pro.
   Не входите в Codex API-ключом: тогда Codex начнёт тратить API-кредиты команды, которые нужны приложению.
   Проверка в CLI: `codex login status`.
4. Зарегистрируйтесь на **vercel.com** (план Hobby, бесплатно).
5. Проверьте заготовку у себя. Распакуйте архив, откройте терминал в папке `hackalem-kit`.
   **Windows:** без виртуального окружения, библиотеки ставятся в обычный Python
   (если в имени пользователя есть кириллица, `.venv` на Windows ломается):
   ```
   python -m pip install -r requirements-dev.txt
   ```
   **macOS:**
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements-dev.txt
   ```
   Дальше везде одинаково:
   ```
   python scripts/check.py
   python -m uvicorn app.main:app --reload
   ```
   Откройте http://127.0.0.1:8000 и понажимайте примеры. Бейдж DEMO без ключа: это нормально.
   (На Windows вместо `python` может быть `py`.)
6. Проверьте Codex: откройте папку `hackalem-kit` в Codex и напишите
   `Прочитай AGENTS.md и объясни в 5 строках, как устроен проект.`
   Потом наберите `$` и посмотрите, появились ли скиллы `spec`, `build` и остальные.

## 2. 13:00: первый коммит (5 минут, делает капитан)

Скопируйте всё содержимое набора в корень командного репозитория, включая скрытые папки `.agents`
и `.codex`, но без `.venv` (виртуальное окружение не переносится, его создают заново):
- macOS: `rsync -a --exclude .venv --exclude logs hackalem-kit/ ПУТЬ_К_РЕПО/`
- Windows: `robocopy hackalem-kit ПУТЬ_К_РЕПО /E /XD .venv logs`

Затем в папке репозитория:
```
git add -A
git commit -m "setup: стартовый набор, раскрыт в README (п. 6.4)"
git push
```
Файл `.env` в git не попадёт: он в `.gitignore`. Каждый делает себе `.env` сам.
Все, включая капитана, в папке репозитория: `git pull`, затем `python scripts/check.py` (должно быть OK).
Библиотеки уже стоят с шага 0.5. На macOS сначала создайте и активируйте `.venv`, как в шаге 0.5.

## 3. Что писать в Codex, по порядку

Откройте папку репозитория в Codex (в приложении: добавить проект, выбрать папку).
Codex спросит, доверять ли папке: отвечайте да, иначе он не подхватит настройки агентов.
Режим по умолчанию подходит: агент правит файлы в папке и запускает команды,
а на доступ в интернет спросит разрешения. Разрешайте.
На Windows режим «Полный доступ» снимает проблемы песочницы. Цена: Codex может менять что угодно
на компьютере без вопросов. Для ноутбука на хакатоне это допустимо, но смотрите, что он делает.

| Когда | Что написать в Codex | Что получится |
|---|---|---|
| 13:00 | `$spec Кейс в docs/CASE.md` | Вопросы (до 3), потом `specs/solution.md`: демо-сценарий, требования, юниты U1..U6 |
| 13:20 | `$build U1` | Агент адаптирован под кейс, тесты зелёные, коммит |
| 13:40 | `$deploy` | Первая публичная ссылка. Вход в Vercel один раз делает человек |
| дальше | `$build U2`, `$build U3`, ... | По одному юниту за раз |
| каждые 2-3 юнита | `$review` | Отчёт в `reviews/`. Потом `$build исправления из последнего ревью` |
| каждый час в :50 | `$checkpoint` | Коммит и push (правило 6.6) |
| ~15:30 | `$evals` | 15-20 тестовых кейсов, точность, стоимость, доля быстрой модели |
| ~16:00 | `Запусти агента judge и дай 3 самых выгодных исправления на 30 минут` | Оценка глазами жюри |

| 17:30 | `$deploy`, затем `$checkpoint` | Финальная ссылка проверена, последний коммит |
| 17:50 | Проверить на платформе, что решение сдано | Последний push до 18:00 |

Если `$` не показывает скиллы, пишите так: `Выполни .agents/skills/spec/SKILL.md` (с нужным именем).
Если сессия идёт больше 60-90 минут, начните новую первым сообщением:
`Прочитай AGENTS.md и docs/progress.md. Продолжаем с U4.`

Бюджет. Codex работает по подписке ChatGPT Pro, API-кредиты команды тратит только приложение.
Держите сессии Codex короткими (60-90 минут). Для `$spec`, `$review` и judge ставьте высокое усилие
рассуждения, для `$build` среднее (выбор модели в приложении). Расход приложения виден в каждом ответе и в `/api/stats`.
Первый `git clone` или `git push` откроет окно входа в GitHub: войдите аккаунтом с доступом к репозиторию команды.

Правила работы втроём:
- Один юнит, один человек, один агент. Два агента не правят один файл одновременно.
- Перед юнитом `git pull`, после юнита коммит и `git push`. Если push отклонён: `git pull --rebase`, затем `git push`.
- Не принимайте код, который никто не прочитал. Хотя бы один тест из ГОТОВО прочитайте глазами.

## 5. Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Codex пишет, что не находит python | Windows: закройте Codex полностью (значок у часов, «Выйти») и откройте снова. Не помогло: системный PATH без Python, см. раздел 9 |
| Codex: `.venv\Scripts\python.exe` не запускается | Кириллица в пути. Удалите `.venv` и поставьте библиотеки в обычный Python: `python -m pip install -r requirements-dev.txt` |
| `check_key.py` пишет FAIL для модели | Поменяйте `MODEL_FAST` или `MODEL_SMART` в `app/config.py` на модель из его списка |
| На сайте бейдж DEMO | В Vercel нет `OPENAI_API_KEY`: добавьте в Settings, Environment Variables, затем `$deploy` |
| Сайт просит войти в Vercel | Это не та ссылка. Нужен адрес вида `https://ПРОЕКТ.vercel.app` |
| Codex завис на команде | Остановите его и напишите: `Не запускай сервер. Проверяй через python scripts/check.py` |
| Тесты красные, времени нет | `$checkpoint` всё равно (коммит с пометкой wip), потом чините |
| Кончился бюджет API | Приложение само отвечает из демо-кэша. Для показа это нормально |
| Пропал интернет | Показывайте локально: `python -m uvicorn app.main:app`, примеры ответят из демо-кэша |
| Конфликт в git | Напишите Codex: `Разреши конфликт аккуратно, ничего не удаляя из чужих изменений, покажи diff` |

- Ссылка на проект работает всё время проверки, 24-28.09 (п. 8.7-8.9).
- Используем AI-агента (Codex), итоговый код в репозитории команды от платформы.
- Решаем один кейс трека. Сначала все обязательные требования кейса, потом остальное.
- README по структуре организаторов: что делает, что реализовано, технологии и архитектура, запуск,

- API-ключи в GitHub не публикуем.

## 9. Windows: если Codex не видит Python или Git

Codex на Windows запускает команды в своей среде и видит только системный PATH.
1. Проверьте: в командной строке `C:\Windows\System32\where.exe python git`. Оба должны найтись.
2. Если Python установлен «только для меня», добавьте его в системный PATH: Пуск, «Изменение системных
   переменных среды», «Переменные среды», в нижнем списке «Path», «Изменить», «Создать»:
   `%LOCALAPPDATA%\Programs\Python\Python313\` и `%LOCALAPPDATA%\Programs\Python\Python313\Scripts\`
   (номер версии свой). Там же должны быть `%SystemRoot%\system32` и `%SystemRoot%`.
3. Перезагрузите компьютер, затем снова откройте Codex.
