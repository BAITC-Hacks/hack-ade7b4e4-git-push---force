# AGENTS.md: Граф денег (HackAlem AI, трек «Финансы», кейс Freedom)

Прочитай целиком перед работой. Проект сменился: финтех-набор (кредиты, антифрод) больше не используется.

## Что строим
AML-инструмент для аналитика банка. Из трёх parquet в `data/` строим направленный граф переводов,
считаем метрики, каждому из 2 248 узлов даём роль, кластер и приоритет, пишем три CSV и экран со схемой сети.
Вопрос аналитика: «кого из 2 248 клиентов смотреть первым и почему».
ТЗ целиком: `docs/TZ.md`. Коротко: `docs/CASE.md`. Контракт данных между частями: `docs/CONTRACT.md`.

## Команды
- Установка: `python -m pip install -r requirements.txt`
- Пайплайн (одна команда, меньше 5 минут): `python -m pipeline --data data --out out`
- Тесты: `python -m pytest -q`
- Ассистент: `python -m uvicorn app.main:app --port 8000`. Запускает человек, не ты.

## Правила
1. Не хардкодить gid и «правильные ответы». Всё считается из данных.
2. Каждая роль и каждая позиция в топе объясняется числами. Формулировки только как гипотезы для проверки
   («признаки консолидации»), никогда как утверждение о виновности.
3. Пайплайн работает локально, без интернета и без API-ключа. LLM только в `app/` и только как опция,
   через `app/llm.py`. Ключ живёт только в `.env`, в git его нет.
4. Никаких внешних данных и выдуманных атрибутов клиентов (ФИО, возраст, доход, организация).
5. gid в JSON и в JavaScript всегда строка: int64 больше 2^53, JS теряет точность.
6. Никаких CDN и загрузок из интернета во время работы экрана: библиотеки лежат в `viewer/vendor/`.
7. Не запускай серверы, `vercel dev` и watchers как проверку. Проверка: `python -m pytest -q`.
8. Новые зависимости только через Амирлана. `requirements.txt` правит Claude.
9. Детерминизм: seed=42 для кластеризации и раскладки графа.
10. Python-интерпретатор: сначала `python`, если нет, то `py`. Виртуальное окружение не создавай.

## Git
- Перед каждым push: `git pull --rebase`, потом `git push`. Никогда не делай force-push.
- Добавляй в коммит только свою зону: `git add viewer/` или `git add app/ static/ tests/test_assistant*.py`.
- Коммит минимум раз в час (правило 6.6). Короткое сообщение на английском: `viewer: search by gid`.
- `.env` никогда не коммитить.
