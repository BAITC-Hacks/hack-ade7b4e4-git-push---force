## 6. Установка и запуск
```
git clone <репозиторий команды>
cd <папка>
python -m pip install -r requirements-dev.txt
cp .env.example .env               # Windows: copy .env.example .env, затем вставить OPENAI_API_KEY
python scripts/check.py            # должно быть OK
python -m uvicorn app.main:app --reload
```
Открыть http://127.0.0.1:8000. Без ключа приложение работает в режиме DEMO на сохранённых ответах.
