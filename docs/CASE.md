# Кейс: Граф денег (Freedom, трек «Финансы»)

Полное ТЗ: `docs/TZ.md`. Данные: `data/` (описание полей: `data/README_dataset.md`).

## Задача
Пайплайн + экран. По графу переводов (81 seed, 4 колена, только исходящие, от 5 000 KZT, июль 2026)
определить роль каждого из 2 248 узлов, разбить сеть на кластеры, ранжировать узлы для проверки.

## Must have (без них решение не засчитывается)
1. Один запуск от сырых parquet до трёх CSV, без ручных шагов, меньше 5 минут на чистой машине.
2. `nodes_roles.csv`: 2 248 строк, у каждого узла role из словаря, role_score 0..1, cluster_id,
   priority_score 0..1, evidence с числами до 200 символов.
3. Для каждой роли формальное правило с порогом. Жюри называет 3 gid, мы за минуту объясняем роль.
4. `clusters.csv`: cluster_id, n_nodes, n_seed, sum_kzt_internal, top_gids, hypothesis.
5. `top_nodes.csv` от 20 строк (rank, gid, role, priority_score, why) + экран: схема сети с направлением
   потоков, ролями, кластерами и поиском по gid.

## Словарь ролей
consolidator, transit, distributor, terminal, coordinator, peripheral. Расширять можно, если задокументировать.

## Ловушки данных (их учёт оценивается)
- 444 узла на 4-м колене без исходящих: обрыв обхода, а не «деньги осели».
- У seed входящие занижены: отношение «отдал / получил» для seed некорректно.
- 19 seed без рёбер, 12 seed только получатели. 16 слабосвязных компонент.
- Порог 5 000 KZT: дробление ниже порога не видно. Нет атрибутов клиентов. Нет разметки ролей.

## Опционально (доп. баллы)
Учёт обрыва 4-го колена, временные паттерны, циклы и повторяющиеся маршруты, аномалии,
устойчивость сети при изъятии топ-N, AI-ассистент аналитика, карточка узла, оценка полноты данных.

## Нельзя
Хардкодить gid, «чёрный ящик» без объяснимых правил, внешние данные, облако/GPU/платные сервисы
для воспроизведения.

## Критерии оценки
Соответствие и работоспособность 25, техническая реализация (включая AI/agentic AI) 25,
README и воспроизводимость 25, ценность 15, потенциал и оригинальность 10.
