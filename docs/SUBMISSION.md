# Текст для кнопки «Сдать решение»

**Название (до 60 символов):**
Граф денег: кого из 2 248 клиентов проверять первым

**Описание:**
Пайплайн и экран для AML-аналитика. Одна команда за 10 секунд превращает выгрузку переводов в роль, кластер и
приоритет для каждого из 2 248 клиентов, с числовым обоснованием по прозрачным правилам и порогам.
Учтены ловушки данных: 444 узла обрыва 4-го колена не считаются конечными получателями, для seed не используется
отношение «отдал / получил». Экран показывает сеть с направлением денег, ролями и поиском по gid, а AI-ассистент
отвечает на вопросы аналитика по графу со ссылками на узлы.
