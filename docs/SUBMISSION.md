**Описание:**
Инструмент для AML-аналитика. Из выгрузки переводов 81 известного участника одна команда за 10 секунд строит роль,
кластер и приоритет с числовым обоснованием для каждого из 2 248 клиентов сети.

Что получает аналитик: топ-30 на проверку с причинами, 8 групп с 2+ известными участниками и гипотезой по каждой,
готовые запросы недостающих данных и аналитическую справку для руководителя. Проверка топ-20 затрагивает 27,7%
оборота сети.

Чем отличается. Роли считаются по прозрачным правилам с порогами, без чёрного ящика. Учтены ловушки данных:
444 клиента на границе выборки не записаны в конечные получатели. Устойчивость проверена: при сдвиге любого порога
топ-20 сохраняется не меньше чем на 85%. На схеме сети есть сценарий «Что если заблокировать». AI-ассистент отвечает
на вопросы по графу через инструменты, каждый gid в ответе проверяется кодом, готовит черновик служебной записки.

Масштаб: синтетический граф той же схемы в 175 тыс. узлов проходит основной расчёт за 71 с. Более 80 автотестов.
