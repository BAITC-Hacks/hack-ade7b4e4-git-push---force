# Питч, 3 минуты

Заполняется командой `$pitch` только из фактов репозитория. Нет цифры: пишем «нет данных».

## Слайды (до 25 слов на слайд)
1. **Проблема:** ... (цифра и источник)
2. **Демо:** живой показ по ссылке
3. **Как работает:** 6 блоков обвязки (контекст, инструменты, память, маршрутизация, логика взаимодействия, мониторинг)
4. **Метрики:** точность N/M, доля быстрой модели X%, стоимость запроса Y тенге, задержка Z с
5. **Пилот:** с кем, на каких данных, какую метрику двигаем, что нужно от партнёра

## Сценарий демо
- 0:00-0:20 Кто пользователь и какая боль
- 0:20-1:40 Сквозной сценарий: кнопка ..., что сказать, пока модель отвечает
- 1:40-2:10 Сценарий на казахском и отбитая prompt injection
- 2:10-2:30 «Что ушло в модель»: маскирование ПДн
- 2:30-3:00 Метрики и пилот
